# MBTI 测试 📊

> 一个简洁的 MBTI 16 型人格测试网页，含四维雷达图、历史记录与结果分享。

回答题目后得到 E/I、S/N、T/F、J/P 四个维度的倾向，匹配 16 型人格，用雷达图直观展示维度分布。

## ✨ 功能

- 🧭 四维度（E/I · S/N · T/F · J/P）计分
- 🕸️ 雷达图展示维度分布（Recharts）
- 📜 历史记录（localStorage 本地保存）
- 🔗 结果分享（可复制 / 生成分享链接）

## 🧱 技术栈

- React + Vite + Recharts
- 纯前端，数据存本地 localStorage

## 🚀 运行

```bash
npm install
npm run dev
npm run build
```
